# SQL Queries

This directory contains SQL queries used to analyze retail sales data in Microsoft SQL Server.

The queries progress from basic SQL concepts to more analytical business reporting, demonstrating practical skills used in data analysis.

---

## Query List

| File | Description |
|------|-------------|
| 01_top_products.sql | Identify the highest-selling products. |
| 02_sales_by_region.sql | Compare total sales across regions. |
| 03_sales_by_category.sql | Analyze sales by product category. |
| 04_monthly_sales_trend.sql | Examine monthly sales trends over time. |
| 05_top_customers.sql | Identify customers with the highest sales. |
| 06_sales_by_segment.sql | Compare sales across customer segments. |
| 07_top_products_by_region.sql | Compare category sales within each region. |
| 08_sales_by_state.sql | Identify the states generating the highest sales. |
| 09_sales_by_city.sql | Identify the cities generating the highest sales. |
| 10_sales_by_ship_mode.sql | Compare sales by shipping method. |
| 11_average_sale_by_category.sql | Calculate average sales by category. |
| 12_order_count_by_region.sql | Count the number of orders in each region. |
| 13_sales_by_subcategory.sql | Compare sales across product sub-categories. |
| 14_top_customers_by_order_count.sql | Identify customers placing the most orders. |
| 15_sales_by_year.sql | Summarize annual sales performance. |
| 16_top_products_per_category.sql | Identify top-selling products within each category. |
