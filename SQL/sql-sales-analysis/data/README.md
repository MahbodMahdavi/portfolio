# Data

This directory contains the dataset used for the SQL Sales Analysis project.

---

## Dataset

**File:** `train.csv`

The dataset contains retail sales transactions and includes information such as:

- Order Date
- Customer
- Segment
- Product
- Category
- Sub-Category
- Sales
- Region
- State
- City
- Ship Mode

The data is used throughout the project to demonstrate SQL querying, business reporting, and sales analysis.

---

## Purpose

The dataset supports analysis of:

- Product performance
- Customer purchasing behavior
- Regional sales trends
- Geographic sales distribution
- Category and sub-category performance
- Shipping methods
- Sales trends over time

---

## Source

The dataset is based on the **Sample Superstore** dataset available on Kaggle.

---

## Notes

This dataset is provided for educational and portfolio purposes. All SQL queries in the `queries` directory reference this dataset.
