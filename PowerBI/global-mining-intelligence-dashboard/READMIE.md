# Global Mining Intelligence Dashboard

## Overview

The Global Mining Intelligence Dashboard is a Power BI project that analyzes global mining operations, commodity production, reserves, ownership, processing capacity, and related operational data. The dashboard is built from a relational mining database and demonstrates data modeling, Power Query transformation, DAX measures, and interactive reporting.

## Objectives

- Build a star schema from a normalized mining database
- Develop an interactive Power BI dashboard
- Analyze production, reserves, capacity, and ownership
- Explore geographic distribution of mining operations
- Demonstrate data transformation and modeling best practices

## Tools

- Power BI Desktop
- Power Query
- DAX
- CSV
- Excel
