# Definitions

## Overview

The `definitions` directory contains reusable data definitions used throughout the publication framework.

Definitions describe the meaning, structure, and constraints of individual data elements independent of publication layout or source systems.

---

## Purpose

Definitions provide a centralized reference for:

- Field descriptions
- Data types
- Units of measure
- Constraints
- Standard labels
- Documentation

---

## Relationship to Other Components

```text
Definitions
      │
      ▼
Metadata
      │
      ▼
Mappings
      │
      ▼
Publication Engine
```

Definitions describe **what a field is**, while mappings describe **where it comes from**.
