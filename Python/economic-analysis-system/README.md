# Economic Index System

This collection contains projects developed as part of an effort to modernize and automate the production of composite economic indices.

## Components

### FRED Economic Data Pipeline
Retrieves and organizes economic data from the Federal Reserve Economic Data (FRED) API.

### Economic Index Modernization
Modernizes a legacy Fortran application into a modular, configuration-driven Python implementation.

### Composite Economic Index Generator
Processes economic indicators into weighted composite indices suitable for analysis and reporting.

Together, these projects demonstrate the complete workflow for acquiring, processing, and analyzing economic time series.
